# Objetivo y alcance

## Objetivo académico

Documentar y validar una plataforma de teleoperación robótica con interfaz XR que pueda reproducirse en contexto universitario.

## Alcance actual

### Implementado actualmente

- Integración funcional de comunicación ZMQ entre computadora de control e interfaz XR.
- Módulos embebidos ESP32-C3 como control de actuadores.
- Interfaz XR funcional para visualización y control de modos de percepción.

### Parcialmente implementado

- Integración de control completo de base móvil y manipulador desde XR.
- Telemetría integral en interfaz XR.
- Flujo de integración total con evidencia homogénea por prueba.

### Fuera de alcance por ahora

- Certificación industrial.
- Protocolo de seguridad formal validado.
- Proceso de calibración formal cerrado.
