# Subsistema del robot móvil

## Descripción

El robot móvil (AGV) es la base de desplazamiento del sistema. En este proyecto, los términos **robot móvil** y **AGV** se usan como equivalentes de la plataforma física de tracción diferencial.

## Implementado actualmente

- Plataforma móvil rehabilitada para integración con control embebido.
- Pruebas de movimiento en superficie plana.

## Parcialmente implementado

- Integración completa de control remoto extremo a extremo en todos los escenarios de prueba.
