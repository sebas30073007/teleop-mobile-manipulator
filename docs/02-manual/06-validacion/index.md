# Validación del sistema

Sección dedicada al diseño experimental, definición de métricas y consolidación de resultados de validación del sistema integrado de teleoperación.

## Objetivo de la validación

Demostrar que el sistema permite a un operador ejecutar tareas logísticas de pick-and-place mediante teleoperación XR con desempeño cuantificable y reproducible en entorno académico controlado.
