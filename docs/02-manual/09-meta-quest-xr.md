# Integración con Meta Quest / Meta XR SDK 83.0

## Rol de la interfaz XR

La interfaz XR permite al operador visualizar el entorno del robot y emitir comandos de interacción remota.

## Base tecnológica documentada

- Meta Quest 3 como dispositivo objetivo.
- Unity como motor de la aplicación.
- Meta XR SDK 83.0.
- Integración de datos con ZMQ.

## Estado de implementación

- **Implementado actualmente:** UI principal, recepción de video, panel LiDAR, panel de estado y cambio de modos.
- **Parcialmente implementado:** control completo del robot y del manipulador desde XR.
