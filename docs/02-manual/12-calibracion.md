# Calibración

## Qué significa calibrar en este sistema

Calibrar implica ajustar parámetros para que el comportamiento físico y digital del sistema sea consistente y repetible.

## Elementos que deberían calibrarse

- Robot móvil.
- Manipulador.
- Sensores.
- Interfaz XR.
- Correspondencia robot físico / representación virtual.
- Respuesta del canal de comunicación.

## Tabla de pendientes de calibración

| Elemento | Variable a calibrar | Método documentado | Estado |
|---|---|---|---|
| Robot móvil | Respuesta de movimiento | No | Pendiente por documentar |
| Manipulador | Posición y repetibilidad | No | Pendiente por documentar |
| Sensores | Alineación y escala | Parcial | Pendiente por documentar |
| Interfaz XR | Mapeo de controles y referencia espacial | Parcial | Pendiente por documentar |
| Comunicación | Tiempos de respuesta y estabilidad | No formal | Pendiente por documentar |
