# Introducción académica

Este proyecto propone la teleoperación de un robot móvil (AGV) con manipulador, usando una interfaz de realidad mixta en Meta Quest.

## Problema que aborda

Las tareas logísticas de almacén requieren interacción física en sitio. La teleoperación busca habilitar operación remota con apoyo de interfaz inmersiva para escenarios académicos de investigación y validación.

## Qué incluye el sistema

- Plataforma de robot móvil con electrónica de control embebido.
- Manipulador acoplado al robot.
- Computadora de control con Python 3.12.
- Comunicación entre subsistemas mediante ZMQ.
- Interfaz XR en Meta Quest (Unity + Meta XR SDK 83.0).
