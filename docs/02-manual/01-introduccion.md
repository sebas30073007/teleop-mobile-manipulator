# Introducción

Este proyecto propone la teleoperación de un robot móvil (AGV) con manipulador, usando una interfaz de realidad mixta en Meta Quest.

## Problema que aborda

Las tareas logísticas en centros de distribución local son el punto que más costo representa dentro del envio de cualquier mercancia. La teleoperación busca habilitar operación remota con apoyo de interfaz inmersiva para personas con discapacidad motriz en miembros inferiores (sector poblacional con tendencia de desempleo).

## Qué incluye el sistema

- Plataforma de robot móvil con electrónica de control embebido.
- Manipulador acoplado al robot.
- Computadora de control con Python 3.12.
- Comunicación entre subsistemas mediante ZMQ, I2C y UART.
- Interfaz XR en Meta Quest (Unity + Meta XR SDK 83.0).
