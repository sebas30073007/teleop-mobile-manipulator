# Subsistema del manipulador

## Descripción

El manipulador corresponde al brazo robótico montado sobre la plataforma móvil para tareas de pick-and-place en entorno de laboratorio.

## Estado técnico

- **Implementado actualmente:** estructura mecánica, pruebas estáticas y evidencia de integración física.
- **Parcialmente implementado:** control remoto integrado en flujo completo XR → control → acción física.

## Notas de consistencia

En el manual se documenta el manipulador como subsistema independiente del robot móvil. Las páginas históricas del repositorio contienen versiones de redacción que deben leerse como avance de desarrollo.
