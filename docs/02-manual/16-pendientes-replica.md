# Pendientes para réplica completa

Esta sección resume los faltantes críticos para pasar de réplica académica parcial a réplica académica completa.

## Pendientes principales

- BOM completo del sistema.
- Esquema eléctrico integral.
- Procedimiento completo de ensamblaje.
- Proceso formal de calibración.
- Medición formal de latencia.
- Protocolo formal de seguridad.
- Código completo de firmware ESP32-C3 (MicroPython).
- Scripts y comandos finales del sistema de control Python 3.12.

## Matriz de pendientes

| Tema | Estado | Impacto en réplica |
|---|---|---|
| BOM | Pendiente por documentar | Alto |
| Esquema eléctrico completo | Pendiente por documentar | Alto |
| Ensamble paso a paso | Pendiente por documentar | Alto |
| Calibración | Pendiente por documentar | Alto |
| Latencia formal | Pendiente por documentar | Medio |
| Seguridad formal | Pendiente por documentar | Alto |
| Firmware completo ESP32-C3 | Pendiente por documentar | Alto |
| Scripts Python de operación | Pendiente por documentar | Alto |
