# Seguridad

## Protocolo de seguridad pendiente de validación

El proyecto no cuenta todavía con un protocolo formal validado. Esta sección define una estructura mínima para trabajo académico controlado.

## Riesgos a considerar

- Riesgos eléctricos por alimentación y electrónica de potencia.
- Riesgos mecánicos por movimiento de base móvil y manipulador.
- Riesgos por operación remota sin confirmación física del entorno.
- Riesgos de atención/situación durante uso de Meta Quest.

## Recomendaciones mínimas temporales

- Operar en área despejada y delimitada.
- Mantener supervisión presencial durante pruebas.
- Verificar paro de emergencia o método inmediato de detención.
- Probar movimientos a baja velocidad antes de pruebas completas.
