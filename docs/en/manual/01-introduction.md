# Introduction

This project proposes the teleoperation of a mobile robot (AGV) with a manipulator, using a mixed reality interface on Meta Quest.

## Problem addressed

Logistics tasks in local distribution centers are the point that represents the greatest cost within the shipping of any merchandise. Teleoperation seeks to enable remote operation supported by an immersive interface for people with motor disabilities in the lower limbs (a population sector with a high unemployment rate).

## What the system includes

- Mobile robot platform with embedded control electronics.
- Manipulator coupled to the robot.
- Control computer with Python 3.12.
- Communication between subsystems via ZMQ, I2C, and UART.
- XR interface on Meta Quest (Unity + Meta XR SDK 83.0).
