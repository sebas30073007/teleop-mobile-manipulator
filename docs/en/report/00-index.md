# Project Report

This report documents the teleoperation robotic system for logistics developed as an engineering terminal project. The narrative proceeds as follows: first, the macroeconomic context that lends urgency to the problem is established; then the operational and social gaps that steer the solution toward inclusion are characterized; and finally, the technical architecture and the methodology followed are described.
