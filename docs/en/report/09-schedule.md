# Schedule

The project is developed during the Spring 2026 semester (January–May 2026), organized into four methodological phases with partial deliveries at the end of each. The structure is sequential with overlap between the implementation phase and the validation phase: the first internal integration tests occur while the system is still under active construction, allowing adjustments before the formal validation sessions.

![Schedule]({{ "/assets/img/full-cronograma.png" | relative_url }})

## Phases, periods, and deliverables

| Phase | Period | Main activities | Deliverable |
|---|---|---|---|
| 1. Analysis | January 2026 | Literature review, logistics task analysis, use-case definition | Prioritized task table + preliminary requirements specification |
| 2. Design | January–February 2026 | Complete requirements, technology selection, mechanical/electronic/software design | Requirements specification + architecture diagram |
| 3. Implementation | February–April 2026 | Robot construction, Python/ZMQ middleware development, XR interface development, incremental integration | Integrated functional prototype + operating protocol |
| 4. Validation | April–May 2026 | User test sessions, metrics collection, results analysis | Results dataset + validation report + final presentation |

## Key milestones

- **Week 4 (January):** Use case defined and preliminary requirements approved
- **Week 8 (February):** Functional mechanical prototype; base Python/ZMQ service initialized with robot communication
- **Week 12 (March):** Robot–server integration verified with measurable latency on the local network
- **Week 14 (March–April):** Complete XR integration; first internal test session of the full teleoperation flow
- **Week 17–18 (May):** Formal validation sessions with operators; SUS data and performance metrics collection
- **Week 20 (May):** Final presentation and delivery of the terminal project report
