# Scope and Limitations

The developed system covers the complete integration of three subsystems in a controlled laboratory environment, spanning the mechanical and electronic design of the robot through to the XR user interface and the coordination middleware.

The scope includes validation in a controlled laboratory environment, focused on demonstrating the feasibility of remote human-machine interaction.

The mechatronic system will enable the remote execution of elementary logistics tasks, integrating manipulation mechanisms and visualization systems that provide the operator with sufficient situational awareness for the task.

Design of a command station and user interface centered on the user, with interface adaptations for operators with reduced lower-limb mobility, prioritizing usability.
