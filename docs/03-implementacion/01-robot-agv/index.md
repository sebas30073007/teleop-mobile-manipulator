# Robot AGV

El subsistema robótico integra una **plataforma móvil de tipo diferencial rehabilitada** con un **manipulador de 3 grados de libertad construido desde cero**. Ambas estructuras comparten la electrónica basada en módulos Puente H y Controlador de Drivers de diseño propio con control embebido ESP32-C3.
